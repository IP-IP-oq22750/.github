<h2>一、渠道大致有五种</h2>
<p>一类是持有整段的机房与运营商，二类是区域代理，三类是二级转售，四类是云市场的地址附加服务，五类是地址转让。</p>
<p>五类的差别在权利层级。层级越靠上，可验证的信息越多，价格也越高；越往下越便宜，出事时越难追。</p>

<h2>二、一手卖家怎么认</h2>
<p>一手卖家的特征是能给出段范围与ASN，且whois里的组织与它自称的主体一致，问什么答什么。</p>
<p>它通常还有自己的工单系统与运维值班，故障时给的是处理进度，而不是一味道歉和安抚。</p>
<h3>验证身份的三步</h3>
<p>第一步查whois组织，第二步查ASN持有者，第三步让对方提供同段内另一个地址的检测结果做比对。</p>
<p>三步都过再谈价格。任何一步含糊，都说明它大概率是转售，后面的承诺也会跟着打折。</p>
<h2>三、代理与转售的取舍</h2>
<p>代理的价值在本地服务：语言通、响应快、能帮你处理实名与付款。这部分价值值得为它付费。</p>
<h3>什么情况下可以用转售</h3>
<p>转售的价值只有价格。省下的钱，本质上是把故障时的等待时间卖给了自己，要算进成本。</p>
<p>用转售不是不行，前提是业务能容忍停摆，或者你手上有备用地址可以随时顶上。</p>
<h2>四、云市场与地址转让</h2>
<p>云市场的地址通常绑定实例，开通快、账单清楚，缺点是归属在云厂商名下，换出去带不走。</p>
<p>地址转让走登记变更，周期长、手续多，但拿到的是可长期持有的段，适合有规划的团队。</p>
<p>做转让时务必确认对方有处置权，且这段地址上没有未结费用或历史纠纷。</p>

<h2>六、下单后怎么验收</h2>
<p>先跑归属与路由检测，三项对不上立刻提工单，别等到用了一周再说，时间越久越难界定责任。</p>
<h3>分批放量的节奏</h3>
<p>再跑两天真实任务，记录晚高峰的丢包与超时。这段时间的数据，比任何承诺都可靠。</p>
<p>验收通过再放量。分批上量能把问题控制在局部，也能给供应商留出处理时间。</p>
<p>对公转账留痕最好，平台担保次之，纯私下转账最差。金额大时，优先选能开发票的渠道。</p>
<p>价格参考：海外原生地址月付从几十元到上千元不等，取决于地区、段大小与是否独享，仅供参考。</p>
<h2>常见问答</h2>
<h3>便宜的渠道一定有问题吗？</h3>
<p>答：不一定。二级转售的成本结构本来就低，但要接受响应慢、可换性差这些代价，关键业务不宜全押。</p>
<h3>需要提供营业执照吗？</h3>
<p>答：部分一手卖家只对企业客户开放，要求资质属于正常流程。个人买家可以走代理，权利层级会低一些。</p>
<h3>一次买多少合适？</h3>
<p>答：按账号数量加两成余量估算。第一次别超过预估用量的一半，跑顺了再补，别一上来就锁量。</p>
<h3>合同里最重要的是哪条？</h3>
<p>答：独占使用与更换机制。这两条决定了出问题时能不能换、换得多快，其余条款可以慢慢谈。</p>
